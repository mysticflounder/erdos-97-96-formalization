# Dated audits and checkpoints

Files here preserve evidence, reviews, negative results, and checkpoint state
at the date stated in each document. They are not current proof-status or
dispatch authorities unless a living plan links to a specific result and
revalidates its source revision.

Do not rewrite old mathematical outcomes merely because the live frontier has
moved. Add a clear historical qualification when a dated document uses words
such as “current,” repair portable repository links, and put new execution
instructions in [`../plans/`](../plans/) or [`../runbooks/`](../runbooks/).

For current state, start at the [documentation map](../README.md), the
[current proof pointer](../proof/CURRENT.md), and the
[obligation registry](../../proof-status/README.md).
