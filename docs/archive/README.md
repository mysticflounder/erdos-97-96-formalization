# Documentation archive

This directory preserves superseded plans, old obligation maps, and dated
research records for provenance. Nothing here is a current dispatch or proof
authority.

Archive sweeps preserve content and carry a dated README explaining why each
file left the living documentation set. A short compatibility pointer may
remain at the former path so old citations continue to resolve. Portable links
to retained repository files should continue to resolve. Links to disposable
historical `scratch/` payloads may intentionally remain unresolved when no
durable artifact survived.

For current state, use the [documentation map](../README.md), the
[current proof pointer](../proof/CURRENT.md), and the
[obligation registry](../../proof-status/README.md).
