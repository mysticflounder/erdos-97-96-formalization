research library, not a live-obligation registry or dispatch queue. Before
reusing any prompt, refresh the target statement, source path, hypotheses,
publish-spine reachability, and axiom boundary from current Lean source and
`proof-blueprint spine`.

`FrontierLiveClosure.lean` snapshot. That file is now an umbrella import; its
old line numbers and several old declarations are obsolete.
