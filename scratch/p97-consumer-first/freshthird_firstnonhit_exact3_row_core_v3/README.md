# FreshThird FirstNonHit exact-three row core v3

This is a bounded wave-data theorem-mining follow-up to the authenticated v2
`COMPLEX_EMPTY` result. It does not add a structural or metric constraint.
Instead, it treats each of the 13 selected equal-radius rows as one monotone
group and greedily deletes row groups with a fresh algebra process per trial.

Discovery uses msolve under two declaration orders. Publication replays the
final candidate and every final drop-one under both msolve orders and an
independent Singular characteristic-zero `dp`/`std` unit-ideal test. A core is
called inclusion-minimal only when all three verdicts agree that the core is
`UNIT` and all three agree that every drop-one is `NONUNIT`.

The permanent one-shot guard is created before generated inputs or solver
calls. Inspect `manifest.prelaunch.json`, then run exactly once:

```bash
uv run python \
  scratch/p97-consumer-first/freshthird_firstnonhit_exact3_row_core_v3/run_core.py
```

This remains trusted cross-engine computation about one fixed finite equality
packet. It is not an exact certificate, a universal theorem, a Lean theorem,
or proof-spine closure.
