# Phase-3 P4 discovery/terminal-proof benchmark

Date: 2026-08-02

This report records the successor `projected_static_v3` implementation of P4,
which separates proof-free SAT discovery from terminal proof production. It is
an exact protocol/regression report, not a solver-speed or mathematical
closure claim.

## Contract implemented

- Sequential discovery calls pass `proof_path=None` to the injected solver.
- Cube-batch discovery calls also pass `proof_path=None`; a cube-local UNSAT
  is recorded as an unverified scheduling result and is never terminal.
- On sequential discovery UNSAT, the runtime writes `terminal.cnf`, rereads it
  and compares its bytes with the coordinator's frozen CNF bytes, then invokes
  a fresh proof-producing solver on that exact path with `.solver.drat` as its
  destination.
- The proof-producing rerun must return UNSAT and leave a nonempty DRAT. The
  existing `drat-trim` checker and checker transcript publication then run with
  the unchanged acceptance condition.
- Terminal-CNF drift, proof-rerun SAT/UNKNOWN/exception, missing or empty
  DRAT, and checker exception/rejection all publish `UNKNOWN` with an
  authenticated failure record.

The frozen v2 driver and frozen `sat_generate.py` source were not changed.
The new solver protocol is authenticated in the v3 configuration as
`proof-free discovery` plus `fresh proof-producing rerun on exact
terminal.cnf`.

## Acceptance matrix

The focused matrix uses injected solver/checker boundaries and checks both
the call arguments and the resulting artifacts:

| transcript | expected boundary | result |
| --- | --- | --- |
| SAT discovery, then UNSAT discovery, then UNSAT proof rerun | discovery calls have no proof path; only the third call receives `.solver.drat` | pass |
| discovery UNSAT, proof rerun SAT | `PROOF_SOLVER_NOT_UNSAT`, no terminal DRAT | pass |
| discovery UNSAT, proof rerun UNKNOWN | `PROOF_SOLVER_NOT_UNSAT`, no terminal DRAT | pass |
| discovery UNSAT, proof rerun emits no DRAT | `MISSING_DRAT` | pass |
| discovery UNSAT, proof rerun emits empty DRAT | `MISSING_DRAT` | pass |
| terminal writer changes CNF bytes | `TERMINAL_CNF_DRIFT`; proof solver is not called | pass |
| checker exception or rejected proof | existing fail-closed checker outcomes | pass |

The terminal proof solver receives `terminal.cnf`, and the test reconstructs
and compares the exact bytes before checking the proof. Cube artifacts retain
their existing full/compact file-policy distinction, but no cube-local DRAT
is generated by discovery.

Observed results: 18 runtime tests, 35 successor-v3 tests, 53 total passed;
the frozen v2 structural suite also passed all 92 tests. Ruff and `py_compile`
passed. No claim is made about end-to-end solver speedup:
the proof-file I/O removed from SAT iterations still needs a bounded real-CNF
measurement separate from this protocol gate.
