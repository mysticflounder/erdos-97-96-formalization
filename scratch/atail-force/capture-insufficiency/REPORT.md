3. `CaptureIncidenceRealization.lean` instantiates the interface over

## The countermodel

17 points: two apexes (`0 = oppApex1`, `1 = oppApex2`), one strict-interior
cap center (`2`), the terminal first-apex row `{3,4,5,6}` with terminal pair
`(3,4)`, the fixed second-apex row `{2,7,8,9}`, the frontier erased pair
`(10,11)`, one descent-step erased pair `(12,13)`, and three extra cap
points `{14,15,16}` (so the cap has card 5 > 4, matching the `surplus`
field).  Every point carries an exact card-4 shell (the shell system's
criticality holds because unforced distances are globally fresh, so every
non-row class is a singleton).  The interior center's row takes at most one
point from each first-apex co-radial group, which is what keeps the sink
constraint satisfied.
