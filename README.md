# Erdős Problems 96 and 97 — solved negatively

**Status: SOLVED (negative answers), 13 September 2026. The project is closed.**

Liam Kruer, Jensen Kohlmeyer, and Liam Price's *Unit distances in convex
polygons* supplies counterexamples to both conjectures. Their complete Lean
construction and our exact Prove2Me adapters passed local kernel checks;
Prove2Me accepted disproofs of both original statements and the combined goal.
See the [resolution and verification record](docs/RESOLUTION.md).

## Results

| Problem | Negative resolution |
| --- | --- |
| **96** | Strictly convex n-point sets can determine Ω(n log log n) unordered unit-distance pairs, ruling out the conjectured O(n) upper bound. |
| **97** | A strictly convex polygon exists in which every vertex has at least four other vertices at distance one. |
| **General fixed-k version of 97** | For every fixed k ≥ 1 and every sufficiently large n, such a set can have at least k unit-distance neighbours at every vertex. |

These statements are Theorem 1.1 and Corollary 1.2 of
[KKP2026](docs/references/kruer-kohlmeyer-price-2026.md). The construction and
upstream formalization are due to the three authors. Adam McKenna prepared
this repository's Prove2Me adapters and closure records.

## Verified disproofs

- [Combined original goal](https://prove2.me/theorems/a6bf5110-b91e-4a2c-9d03-8b51a8a9e6ad).

The [submission packet](prove2me/submissions/negative-resolution-20260913/README.md)
contains the pinned manuscript and original Lean source, exact adapters,
source hashes, local checks, independent transfer audits, and server receipts.
The checked environment is Lean 4.33.1 with Mathlib
`0df444a360eaa60ab8c11dca51a86af692955474`; the final adapters use only
`propext`, `Classical.choice`, and `Quot.sound`.
